# Logo slot

The website looks for `assets/nyu-logo.svg` (or change the `src` in `index.html`).

Download the official NYU logo from NYU's brand/logo resources while signed in with your NYU account,
save it here as `nyu-logo.svg` (a white/reversed version works best on the violet bar), then commit it.

Until the file exists, the page shows the plain text "NYU" instead, so nothing breaks.
